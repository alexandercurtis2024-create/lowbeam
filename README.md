# Lowbeam — Public Demo

Live demo: https://alexandercurtis2024-create.github.io/lowbeam/

This repository contains **only the compiled production build** of Lowbeam, a privacy-aware navigation prototype. No source code is published here.

Lowbeam compares driving routes against documented ALPR locations and shows the time-vs-surveillance tradeoff, with explicit honesty when data is sparse.
